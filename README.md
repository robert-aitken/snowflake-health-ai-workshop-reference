# Snowflake Health AI Workshop Reference

Personal workshop reference based on Snowflake healthcare AI workshop material and demonstrations.

This repository is maintained as a learning reference for healthcare-focused AI, analytics and application development workflows within the Snowflake ecosystem.

## Workshop focus

The workshop explored how Snowflake AI capabilities can be applied to healthcare and analytical use cases, including:

- Snowflake Cortex AI
- Document AI
- Cortex Analyst
- Cortex Search
- Snowflake Notebooks
- Streamlit applications
- Healthcare and research-oriented analytical workflows

Topics included working with structured and unstructured data, document processing, AI-assisted analytics, semantic search, notebook-based development and interactive data applications.
